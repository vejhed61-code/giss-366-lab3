# GISS 366/368 · Lab 3 Starter Repository

This is the starter repository for **Lab 3: HTML & CSS in Practice**, part of Week 4 in our GISS 366 Web Mapping & Web GIS course at WNMU.

## Before you clone this

Don't clone this repository directly. Instead:

1. Click the green **Use this template** button above, then **Create a new repository**.
2. Set the visibility to **Public** (required for GitHub Pages to work on a free account).
3. Create the repository under your own GitHub account.
4. Clone *that* new repository, following the Lab 3 instructions.
